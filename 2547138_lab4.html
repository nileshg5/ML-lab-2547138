def evaluate_split(test_size, k_value, random_state=42):
    X_train, X_test, y_train, y_test = train_test_split(
        X_scaled, y, test_size=test_size, random_state=random_state, stratify=y
    )
    model = KNeighborsClassifier(n_neighbors=k_value)
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    return {
        'split': f'{int((1 - test_size) * 100)}:{int(test_size * 100)}',
        'train_size': len(X_train),
        'test_size': len(X_test),
        'accuracy': accuracy_score(y_test, predictions)
    }

X_train_80, X_test_80, y_train_80, y_test_80 = train_test_split(
    X_scaled, y, test_size=0.2, random_state=42, stratify=y
)

n_train = len(X_train_80)
raw_k = np.sqrt(n_train)
rounded_k = int(round(raw_k))
if rounded_k % 2 == 1:
    heuristic_k = rounded_k
else:
    lower_k = max(1, rounded_k - 1)
    upper_k = rounded_k + 1
    heuristic_k = lower_k if abs(raw_k - lower_k) <= abs(upper_k - raw_k) else upper_k

print('Training samples:', n_train)

Distance Metrics

Euclidean Distance measures the straight-line distance between two points. It is the most common distance metric for KNN when features are scaled properly. It works well when nearby points in all directions should be treated similarly.

Manhattan Distance measures distance by adding the absolute differences across features. It can be useful when the data has many dimensions or when outliers affect straight-line distance too much. It is often preferred when movement is more grid-like than diagonal.

Euclidean distance is often preferred for smooth numeric data. Manhattan distance is often preferred when the feature space is sparse or noisy.

def plot_boundary(ax, X_data, y_data, k_value):
    model = KNeighborsClassifier(n_neighbors=k_value)
    model.fit(X_data, y_data)
    x_min, x_max = X_data[:, 0].min() - 1, X_data[:, 0].max() + 1
    y_min, y_max = X_data[:, 1].min() - 1, X_data[:, 1].max() + 1
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 300), np.linspace(y_min, y_max, 300))
    grid_predictions = model.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    boundary_cmap = ListedColormap(['#dce9f7', '#f8d9d7'])
    point_cmap = ListedColormap(['#1f77b4', '#d62728'])
    ax.contourf(xx, yy, grid_predictions, alpha=0.45, cmap=boundary_cmap)
    ax.scatter(X_data[:, 0], X_data[:, 1], c=y_data, cmap=point_cmap, edgecolor='k', s=18)
    ax.set_title(f'K = {k_value}')
    ax.set_xlabel('Principal Component 1')

Task 6: Comparative Study with Regression (Lab 3 Integration)

Regression evaluation focuses on measuring the magnitude of prediction errors, whereas classification evaluation focuses on whether the predicted class label is correct.

R² Score vs Accuracy: R² Score measures how well a regression model explains the variation in continuous target values. Accuracy measures the percentage of correctly classified samples. Both indicate overall model performance, but they are used for different prediction tasks.

RMSE vs F1-Score: RMSE measures the average prediction error while giving higher weight to larger errors. F1-Score combines Precision and Recall into a single metric and evaluates the balance between correctly identifying positive cases and avoiding false predictions.

MAE vs Confusion Matrix: MAE calculates the average absolute difference between predicted and actual values in regression. The Confusion Matrix summarizes classification outcomes by showing True Positives, True Negatives, False Positives, and False Negatives, providing detailed insight into prediction correctness.

Continuous Prediction vs Classification: Regression predicts continuous numerical values such as GPA or medical costs, and its performance is evaluated based on prediction errors. Classification predicts discrete class labels such as benign or malignant, and its performance is evaluated based on correct and incorrect decisions.

Inference

Regression metrics such as MAE, MSE, RMSE, and R² Score evaluate how close predicted values are to the actual continuous values. Lower MAE, MSE, and RMSE indicate better prediction accuracy, while a higher R² Score indicates that the model explains more variation in the data. These metrics measure the magnitude of prediction errors rather than whether a decision is correct. This evaluation approach was used in Lab 3 to assess Linear Regression performance.

Classification metrics evaluate the correctness of predicted class labels instead of numerical errors. Accuracy measures overall correctness, Precision measures the correctness of positive predictions, Recall measures the ability to detect actual positive cases, F1-Score balances Precision and Recall, and ROC-AUC measures the model's ability to distinguish between classes across different thresholds.

Accuracy alone is insufficient for medical diagnosis because a model may achieve high accuracy while still missing patients with cancer. False negatives are more critical than false positives in healthcare. Therefore, Recall is essential because it minimizes missed cancer cases, and ROC-AUC provides a threshold-independent measure of the model's discrimination ability. Overall, regression evaluation emphasizes prediction error, whereas classification evaluation emphasizes decision quality and reliable identification of class labels.

Task 7 - Analytical Questions

  1. Why is KNN called a lazy learning algorithm? KNN does not build a separate training model during the learning stage. It stores the training data and waits until prediction time to compute distances. That is why it is called lazy learning.

  2. Why is feature scaling required in KNN? KNN depends on distance, so features with larger numeric ranges can dominate the result. Scaling puts every feature on a similar scale. This makes the distance calculation fair.

  3. Explain heuristic K selection using √n. A common rule is to start with K equal to the square root of the number of training samples. This gives a reasonable balance between noise sensitivity and smoothing. The value is often adjusted to an odd number to avoid ties.

  4. Why is cross-validation more reliable than a single train-test split? Cross-validation tests the model on several different folds of the data. This gives a more stable estimate of performance. A single split can depend too much on one random division.

  5. How does K affect the bias-variance trade-off? Small K values usually give low bias and high variance. Large K values usually give higher bias and lower variance. The best K gives a balanced result.

  6. Why is Recall more important than Accuracy in cancer prediction? Recall checks how many actual cancer cases are found by the model. Missing a real cancer case can be very dangerous. That is why recall is often more important than accuracy in this task.

  7. What is the limitation of very large K values? Very large K values make the model too smooth. It can ignore useful local patterns in the data. This can lead to underfitting and weaker predictions.
